Relative Grassmannian과 relative Plücker embedding

본문 미작성 · 구조만 예약한 빈 문서

상태. 이 페이지는 빈 껍데기다. 목차와 완료 조건만 예약했으며, 아래 항목을 실제로 계산하거나 증명했다고 간주하면 안 된다.

자리. ordinary Grassmannian의 국소 계산을 vector bundle의 fiberwise 계산으로 올리는 자리.

이 문서가 답할 질문

  • Gr_X(k,E)의 점과 tautological bundle을 어떤 convention으로 고정할 것인가
  • local trivialization에서 ordinary Grassmannian chart가 어떻게 재현되는가
  • relative Plücker line bundle과 embedding은 어떻게 정의되는가
  • base 방향과 fiber 방향을 계산에서 어떻게 구별할 것인가

완료 조건

한 개의 nontrivial base 예에서 local trivialization 두 개를 쓰고 relative Plücker transition을 직접 맞춘다.
