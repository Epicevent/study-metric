Grassmann bundle의 수직접다발과 canonical class

상태. 이 페이지는 빈 껍데기다. 목차와 완료 조건만 예약했으며, 아래 항목을 계산하거나 증명했다고 간주하면 안 된다.

자리. relative Grassmannian·Reineke tower의 구성과 twisted metric 사이.

이 문서가 답할 질문

  • Relative Grassmannian π: Gr_X(k,E)→X의 vertical tangent bundle은 어떤 bundle 식으로 쓰이는가
  • 0→T_{X_r/X_{r-1}}→TX_r→π_r^*TX_{r-1}→0은 tower를 따라 어떻게 반복되는가
  • Grassmann bundle의 canonical 또는 anticanonical class formula는 tautological bundle과 det E로 어떻게 표현되는가
  • 이 공식이 framed quiver variety의 Fano chamber 조건에 어떻게 들어가는가

완료 조건

한 단계의 vertical tangent와 canonical class를 bundle notation으로 유도하고, tower 전체의 anticanonical class가 단계별로 누적되는 식을 적는다.
